# Harbour.Space Apprenticeship Program — Practical Challenge

A responsive web implementation of the Harbour.Space Data Science Apprenticeship Program page, built as part of a practical development challenge.
- Access Hosted Server: https://harbour-space-practical-challenge.netlify.app

## Features

- Responsive layout for desktop and mobile.
- Dynamic scholarship information fetched from the Harbour.Space API.
- Instructor profiles and testimonials.
- Interactive FAQ section with category filtering and expandable answers.
- Reusable React components and state management with Zustand.

## Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** Zustand
- **Data Source:** Harbour.Space API

## Getting Started

### Prerequisites

- Node Version ```v22.12.0```.
- Node.js
- npm

### Installation

Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/key-joshua/harbour-space-apprenticeship-program-practical-challenge.git
cd harbour-space-apprenticeship-program-practical-challenge
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## API Integration

The application retrieves scholarship data from the Harbour.Space API through a Next.js API route, which makes the data available to the frontend.
